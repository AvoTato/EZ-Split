# GitHub Branching Commands
**Basic Git Commands**
1. git checkout main # Start on main
2. git pull origin main # Get latest code
3. git checkout -b feat/my-feature # Create new branch
4. git add .
5. git commit -m "Add newfile.js"
6. git push origin feat/my-feature
7. git push -u origin feat/ror-calander-supplier (only use this if u already push to github previously)

**To delete branch**
1. git branch -d branch-name # safe 
2. git branch -D branch-name # force delete
